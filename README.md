# MyLike

把抖音「喜欢」过的视频完整保存到本地，随时筛选、搜索、洗牌播放——不依赖抖音 App，几万条内容也能流畅浏览。

> 仅用于整理你自己的喜欢列表，仅供个人使用。

## 下载安装（GitHub Release）

1. 到本仓库的 **[Releases](../../releases)** 页面下载最新版 **`MyLike.exe`**（推荐，直接下载即可，无需解压）
2. 放到任意目录（建议固定文件夹，如 `D:\MyLike`），双击运行——**无需安装 .NET、无需安装环境**

> 如果浏览器 / 下载工具拦截 exe，可改下 `MyLike-win-x64.zip`（内容就是同一个 exe，解压后双击即可）。

### Windows SmartScreen 提示怎么办

应用未购买代码签名证书，Windows 首次运行未签名程序时会弹出「Windows 已保护你的电脑」蓝色警告，这是**正常现象**，按下面三步放行：

1. 在弹出的窗口中点击 **「更多信息」**
2. 点击 **「仍要运行」**
3. 之后即可正常使用（同一台电脑只需操作这一次）

> 为什么要点：本应用未购买商业代码签名证书（年费较高），Windows 对一切未签名下载程序都显示该警告。应用不含任何恶意代码，且源码完全开源，可自行审查。

> 其他要求：Windows 10/11；系统需有 WebView2 Runtime（Win10/11 一般随 Edge 自带，缺失时应用会给出下载指引）。

## 快速上手

1. **登录**：点右上角「登录」→ 在弹出的窗口完成抖音登录（支持扫码）→ 成功自动关窗
2. **采集**：点「❤ 采集」抓取你的完整喜欢列表，顶部进度条实时显示进度，采完自动停止
3. **播放**：点任意卡片从该条顺序播放；点「洗牌播放」随机播放当前筛选结果

> 更完整的教程与常见问题在应用内：「帮助 → 使用教程 / 常见问题」。

## 功能

- **增量采集**：再次采集只补新内容，自动去重，翻到断点即停
- **断点续采**：中途失败 / 限流 / 手动停止后，从上次进度继续，不遗漏不重复
- **风控自愈**：接口被限自动弹滑块验证窗，恢复后自动续采，全程无需盯守
- **多维筛选**：全部 / 视频 / 图集分类 + 年份 + 月份 + 标题作者搜索，筛选结果与播放联动
- **洗牌播放**：随机播放当前筛选范围；图集自动轮播；一键跳原页看评论，返回续播
- **数据管理**：勾选批量删除；`.dylist` 导入 / 导出备份，换电脑零成本迁移

## 快捷键

| 按键 | 功能 |
|------|------|
| `空格` | 播放 / 暂停 |
| `↑` / `PageUp` · `↓` / `PageDown` | 上一首 / 下一首 |
| `←` / `→` | 快退 / 快进 5 秒（图集为翻张） |
| `F` / 双击画面 | 全屏开关 |

## 数据与隐私

- 全部数据在本机 `%LOCALAPPDATA%\DouyinShuffle\`：列表文件 `Data\default\items.dylist`、进度状态 `state.json`、日志 `init.log`
- 播放链接有时效，**本地不保存任何播放链接**，播放时实时获取
- 登录信息只存本机，不上传任何服务器
- 重装 / 换机前用「导出」备份，新环境「导入」恢复

## 从源码构建（开发者）

```bash
# 环境:Windows 10/11 + .NET 10 SDK

# 调试运行(框架依赖)
dotnet build src/DouyinShuffle.Win/DouyinShuffle.Win.csproj -c Debug

# 发布自包含单文件(免装 .NET,产物只有一个 MyLike.exe,实测点击即用)
dotnet publish src/DouyinShuffle.Win/DouyinShuffle.Win.csproj -c Release
```

发布产物在 `bin/Release/net10.0-windows/win-x64/`（或指定 `-o` 目录），打包 zip 即可分发。
详见 [GitHub Release 发布流程](#发布到-github-release)。

## 发布到 GitHub Release

```bash
# 1. 首次推代码(仓库尚未配置远程)
git remote add origin https://github.com/<你的用户名>/MyLike.git
git add -A && git commit -m "init"
git push -u origin main

# 2. 打标签即自动发布(仓库已配置 GitHub Actions 工作流)
git tag v1.0.0
git push origin v1.0.0
```

推标签后，`.github/workflows/release.yml` 会自动构建并生成 `MyLike-win-x64.zip` 附件到对应 Release。
也可以在 GitHub 网页上手动建 Release 上传 zip。

## 常见问题

- **采集数量比抖音显示的喜欢数少？** 正常：已删除 / 下架 / 私密的内容接口不再返回，返回但无法播放的会标记「失效」。
- **采集太快被限流？** 平台行为。按提示完成滑块验证或稍候即可，已采数据都在。
- **视频黑屏无画面？** 多为 H.265 编码且系统缺 HEVC 解码，会自动尝试备用链接；也可给 Win10 装「HEVC 视频扩展」。
- **支持收藏夹吗？** 当前版本仅支持「喜欢」列表。
